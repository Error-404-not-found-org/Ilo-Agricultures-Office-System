# Shared App Layer

Shared code belongs here when it is reused across multiple feature modules.
Keep feature-specific logic in `features/` instead.

Suggested folders:

- `components/` for reusable UI.
- `hooks/` for cross-feature hooks.
- `services/` for common service helpers.
- `types/` for shared domain contracts.
- `utils/` for small pure helpers.
- `constants/` for app-wide constants.
